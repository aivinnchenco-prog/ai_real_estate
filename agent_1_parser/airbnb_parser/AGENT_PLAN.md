## Правила работы (READ FIRST)

1. Идёшь по фазам строго сверху вниз. Внутри фазы — по одной задаче за раз.
2. Для каждой задачи: (а) проверь, что зависимости сделаны → (б) реализуй → (в) напиши и прогони тест/функциональную проверку → (г) когда выполнен критерий «готово» — отметь `[x]`, сделай коммит с названием задачи, переходи к следующей.
3. **🔑 ЧЕЛОВЕК** — если задача помечена так, она требует того, что можешь дать только пользователь (ключ, аккаунт, доступ, бюджет, логин, решение по деньгам). **Остановись, попроси у пользователя ровно этот предмет с точной инструкцией, дождись — и продолжай.** Не подделывай и не «заглушай» секреты.
4. Если задача блокирована или пользователь сказал «пропусти» — пометь `[~] skipped`, запиши причину, иди дальше.
5. После каждой фазы — краткий отчёт: что сделано, что дальше, какие 🔑-пункты висят на пользователе.
6. Секреты никогда не коммить: только переменные окружения / `.gitignore`.
7. **Гардрейлы** (ниже) — рискованные действия с платформами сам не выполняешь, спрашиваешь явное «go».
8. Перед любым действием, которое отправляет сообщения, публикует в публичный доступ, тратит деньги или трогает реальные внешние аккаунты — спроси подтверждение.

## Контекст проекта

- Стек: Python, aiogram 3, seleniumbase (undetected Chrome), loguru, lxml. Сервер Ubuntu 22.04, путь `/root/airbnb.ru`.
- Источник правды: Google Таблица (схема — в отдельном файле таблицы). Медиа: Google Drive. LLM: Anthropic API. Публикация: Telegram Bot API и др.
- Держи код модульным: `sheets.py`, `drive.py`, `enrich.py`, `parsers/`, `outreach/`, `publish/`, `partners/`, `tests/`.

## 🔑 Что может дать только человек (запрашивай по мере подхода)

- Google service account JSON (включены Sheets API + Drive API), таблица и папка расшарены на его email.
- Перевыпущенный токен Telegram-бота.
- Созданные Telegram-каналы «Аренда» и «Продажа» + бот добавлен админом.
- Рекламные аккаунты (Meta/Target) и одобрение бюджета.
- Домен + лендинг.
- Условия партнёрства (сплит %, территории).
- Любые логины/ключи сторонних сайтов и порталов.
- Явное разрешение на живую рассылку и публичную публикацию.

## Гардрейлы (без явного OK человека не автоматизируешь)

- Массовая холодная рассылка (WhatsApp/FB/LINE/email) — только полу-авто, отправляет/подтверждает человек.
- Массовый постинг в FB-группы/Marketplace — с лимитами и подтверждением.
- Всё, что может привести к бану аккаунтов или нарушает правила площадок.
- Траты денег и принятие условий сделки.
- Хранение/вывод секретов в открытом виде.
