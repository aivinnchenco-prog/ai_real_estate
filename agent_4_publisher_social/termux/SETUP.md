# Настройка телефона — пошагово

От чистого телефона до работающего раннера. Порядок важен: каждый шаг
опирается на предыдущий.

Ориентировочно 40–60 минут, из них половина — вход в аккаунты соцсетей.

---

## Шаг 0. Что нужно до начала

- Телефон на **Android 11 или новее** (нужна беспроводная отладка).
- Зарядка рядом — телефон будет жить подключённым к питанию.
- Wi-Fi (домашний, стабильный).
- Логины/пароли от всех соцсетей, которые публикуешь.

Проверить версию: **Настройки → О телефоне → Версия Android**.

---

## Шаг 1. Гигиена телефона (10 мин)

Делается один раз, но экономит недели отладки.

**1.1. Отключить автообновление приложений.**
Play Store → аватар → Настройки → Настройки сети → Автообновление
приложений → **Никогда**.

Причина: обновление Instagram или TikTok меняет интерфейс, и сценарии
`uiautomator2` перестают находить элементы. Обновляешь вручную, когда готов
чинить.

**1.2. Отключить автообновление системы.**
Настройки → Обновление ПО → выключить автозагрузку.

Причина: обновление Android перезагружает телефон и роняет пару
беспроводной отладки. Если ты в отъезде — узнаешь об этом по тишине.

**1.3. Отключить экономию батареи для нужных приложений.**
Настройки → Приложения → выбрать приложение → Батарея → **Без ограничений**.

Сделать для: **Termux**, **Termux:Boot**, Instagram, TikTok, остальных
соцсетей из твоего списка.

**1.4. Выключить блокировку экрана.**
Настройки → Безопасность → Блокировка экрана → **Нет**.

Причина: код `ensure_unlocked()` умеет смахивать свайп-локскрин, но PIN и
отпечаток он обойти не может. Телефон стоит дома — риск невелик.

**1.5. Отключить поворот экрана** (закрепить портрет) и **тёмную тему**,
если она включена — сценарии писались под светлую.

---

## Шаг 2. Режим разработчика (2 мин)

1. Настройки → **О телефоне**
2. Тапнуть по «**Номер сборки**» 7 раз подряд
3. Появится «Вы стали разработчиком»

Затем: Настройки → Система → **Для разработчиков** → включить:
- **Отладка по USB**
- **Беспроводная отладка**
- **Не выключать экран** (при зарядке экран не гаснет)

⚠️ Беспроводную отладку **не выключай** — на ней держится вся схема.

---

## Шаг 3. Вход в соцсети (15–20 мин)

Заходи в каждое приложение **вручную, с этого телефона**, и доведи до
рабочего состояния:

- Instagram (аккаунт Business или Creator)
- TikTok (Business)
- YouTube (нужный канал выбран)
- LinkedIn
- X / Twitter
- Facebook (для Groups и Marketplace)

**Обязательно для каждого:**
1. Войти и остаться залогиненным (не «выйти после»).
2. **Пройти все первичные экраны** — «Разрешить уведомления»,
   «Включить геолокацию», туры по интерфейсу, предложения подписки.
   Любой непройденный попап позже сломает сценарий.
3. **Выдать разрешения** на Фото/Медиа и Камеру — иначе приложение не
   увидит залитые файлы.
4. Сделать **один пробный пост руками**. Это проверит, что аккаунт не под
   ограничением и что публикация вообще проходит с этого устройства.

Не пропускай пункт 4. Половина «загадочных» провалов автоматизации — это
проблемы аккаунта, а не кода.

---

## Шаг 4. Установка приложений Termux (5 мин)

**Только из F-Droid.** Версии в Play Store заморожены и на новых Android
ломаются.

1. Открыть **f-droid.org** в браузере телефона, скачать и установить F-Droid.
2. В F-Droid найти и установить:
   - **Termux**
   - **Termux:Boot** (автозапуск после перезагрузки)
   - **Termux:API** (заряд, wake-lock)

3. **Запустить Termux:Boot один раз вручную** — иначе автозапуск не
   активируется. Открыл, увидел пустой экран, закрыл. Этого достаточно.

---

## Шаг 5. Перенос проекта (5 мин)

Открыть **Termux** и дать доступ к памяти:

```bash
termux-setup-storage
```
(появится системный запрос — разрешить)

Дальше один из вариантов.

**Вариант А — через git** (удобно обновлять код потом):
```bash
pkg install -y git
git clone ВАШ_РЕПОЗИТОРИЙ ~/publisher-social
```

**Вариант Б — скопировать папку.**
Перекинь папку «Publisher social» на телефон (кабель, Google Drive,
Telegram — как угодно), затем:
```bash
mkdir -p ~/publisher-social
cp -r /sdcard/Download/"Publisher social"/* ~/publisher-social/
```

Проверить, что код на месте:
```bash
ls ~/publisher-social/src/publisher_social
```
Должны быть `pipeline.py`, `channels/`, `android/`.

---

## Шаг 6. Bootstrap (5 мин)

```bash
bash ~/publisher-social/termux/bootstrap.sh
```

Скрипт поставит python, adb, зависимости, разложит команды в `~/bin` и
пропишет автозапуск. В конце сам предложит спарить телефон — см. шаг 7.

---

## Шаг 7. Парринг телефона с самим собой (3 мин)

Делается **один раз**. Дальше порт находится автоматически.

1. Открыть Настройки → Для разработчиков → **Беспроводная отладка**
2. Тапнуть «**Подключение с помощью кода сопряжения**»
3. Появится окно: **IP-адрес и порт** + **6-значный код**
4. Не закрывая это окно, переключиться в Termux (оно живёт ~1 минуту)
5. Скрипт спросит — ввести **порт сопряжения** и **код**

Если что-то пошло не так, повторить в любой момент:
```bash
pub connect
```

💡 Держи Termux и Настройки в режиме разделённого экрана — так окно с кодом
не закроется при переключении.

---

## Шаг 8. Ключи Notion (2 мин)

```bash
nano ~/publisher-social/.env
```

Вписать:
```
NOTION_API_KEY=secret_ваш_ключ
NOTION_DB_ID=ваш_id_базы
```

Сохранить: `Ctrl+O`, `Enter`, `Ctrl+X`.

`ANDROID_SERIAL` не трогай — его проставляет `connect_self.sh` сам.

---

## Шаг 9. Telegram-уведомления (5 мин)

1. В Telegram написать **@BotFather** → `/newbot` → придумать имя →
   получить **токен**.
2. Написать своему новому боту любое сообщение (иначе он не сможет
   ответить первым).
3. Открыть в браузере: `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
   и найти `"chat":{"id":123456789` — это **chat_id**.

```bash
nano ~/.publisher/runner.env
```
Вписать:
```
TG_BOT_TOKEN=123456:AAA...
TG_CHAT_ID=123456789
DEVICE_LABEL=phone-1
```

Проверить:
```bash
pub notify
```
Сообщение должно прийти в течение пары секунд.

---

## Шаг 10. Проверка без публикации ⚠️

**Не пропускай.** Тут ловятся почти все ошибки настройки.

```bash
pub test
```

Что должно быть в выводе:
- `"ok": true` и серийник вида `127.0.0.1:XXXXX` — телефон видит сам себя
- список объектов из Notion — ключи и база работают

Если `ok: false` → вернуться к шагу 7.
Если очередь пуста → проверь, что в Notion есть объект в статусе
`ready_to_post`.

---

## Шаг 11. Первая публикация под присмотром

**Сначала UI-режим** — дойдёт до экрана публикации, но не нажмёт «Опубликовать»:

```bash
cd ~/publisher-social && export PYTHONPATH=src
python -m publisher_social publish --page-id PAGE_ID --channel instagram_reel --ui
```

Смотри на экран телефона. Приложение должно открыться, выбрать видео,
дойти до описания. Если где-то застряло — записывай, на каком шаге.

**Потом одна живая публикация:**
```bash
python -m publisher_social publish --page-id PAGE_ID --channel instagram_reel --live
```

Проверь пост в приложении глазами. Только после этого — автомат.

---

## Шаг 12. Запуск раннера

```bash
pub start
```

Проверить:
```bash
pub status     # 🟢 работает
pub logs       # живой лог, Ctrl+C для выхода
```

Телефон можно положить на зарядку и оставить. Дальше он работает сам:
раз в 5 минут ходит в Notion, а live-запуск обрабатывает ровно одну соцсеть,
пишет тебе в Telegram результат и останавливается до следующего `pub start`.
Это пошаговый режим проверки после каждого канала. Если Telegram временно
недоступен, отчёт остаётся в локальном outbox, и следующий live-запуск не
начнёт новую соцсеть до его доставки.

---

## Шаг 13. Проверка автозапуска

Обязательно проверь до отъезда:

1. Перезагрузить телефон
2. Подождать 2 минуты, **не открывая Termux**
3. Должно прийти сообщение «🚀 Раннер запущен»

Если не пришло:
- Termux:Boot запускали вручную хотя бы раз? (шаг 4.3)
- Экономия батареи для Termux отключена? (шаг 1.3)
- Посмотреть: `cat ~/.publisher/boot.log`

---

## Ежедневная работа

Со стороны — почти ничего. Кладёшь объекты в Notion со статусом
`ready_to_post`, раннер сам их разбирает.

| Что | Команда |
|---|---|
| Как дела | `pub status` |
| Смотреть лог | `pub logs` |
| Опубликовать сейчас | `pub once` |
| Остановить | `pub stop` |
| Запустить | `pub start` |

---

## Если что-то сломалось

| Симптом | Что делать |
|---|---|
| Пришло «⚠️ Нет ADB-подключения» | Настройки → Для разработчиков → Беспроводная отладка ВКЛ, затем `pub connect` |
| Тишина больше суток | Termux убит системой. Открыть, `pub start`, проверить шаг 1.3 |
| «⏱ Цикл повис» | Приложение показало неожиданный попап. Открыть его руками, пройти, перезапустить |
| Канал стабильно `[FAIL]` | Обновилось приложение → сломался UI-сценарий. Проверь `pub logs` |
| «🔋 Заряд 18%» | Телефон отключился от зарядки |

## Чек-лист перед отъездом

- [ ] `pub status` → 🟢

- [ ] Автообновления приложений и системы выключены
- [ ] В Notion есть объекты в очереди на несколько дней вперёд
- [ ] Хотя бы одна публикация прошла живьём и видна в соцсети
